变更规模52 次提交 · 430 个文件

一句话：本版本主线是版本分层与离线授权（Edition Tiering + License）从规格到门禁、配额、签发工具与管理界面的完整落地；另一条线是 DAM 资源体验与媒体播放（预览 / PDF / 大图 / 音频播放 / 跨域嵌入 / 统计接入），并完成媒体服务器品牌 Knox → PowerMedia 重塑；同时补齐管理端五语译文、社区版拆分与工作流待办审核体验。

更新记录

＋ 新增

  • 版本分层能力位与配额总门禁：能力位越界 403、配额超限 409、授权到期只读 402，总开关 powercms.license.enforce-edition-boundaries 生产默认开启。
  • 离线授权激活与续期：离线激活、P3 短激活码（策略 C）离线续期、公钥指纹钉扎、T-30 续期横幅与签名吊销名单导入。
  • 媒体服务器附属组件授权 grant（专业版以上）：数量配额与单机最大并发配额，未领 grant 拒绝接入。
  • 离线授权签发工具 tools/license-tool：独立 Maven 工程，覆盖签发 / 短激活码 / 规范化 JSON，公钥入库 keys/pubkey-powercms-2026.pem。
  • 资源详情 PDF 阅读器与大图查看：图片支持点击查看大图，viewerRights 授权贯通。
  • 音频播放重做：按 music-player 重做音频预览（默认不自动播放），随附 docs/music-player.html 播放器参考页。
  • 播放页对接统计通道：播放页接入 CMS12 汇总统计，播放代码新增「启用统计」开关。
  • 内容搜索视图模式：缩略图 / 列表 / 表格三种视图，带内容模型预览图。
  • 只读审核弹窗：按内容模型布局渲染待办字段（新增 ContentReviewModal / ContentReadOnlyView / ContentMediaValue）。
  • Java 回归门禁 CI（.github/workflows/test.yml）：cms-core 单测与集成测试，H2 内存库，无需外部数据库 / Docker / npm 构建。
  • react-dam 独立仓库站点包：github.com/knoxlab/react-dam 以子模块引用，站点包 react-dam.zip 随本 Release 发布。

◈ 优化

  • 媒体服务器品牌重塑：媒体库与管理端 Knox → PowerMedia，界面文案与文档统一更名；自动探活直至 UP，操作区图标化并直达媒体服务器后台。
  • 媒体库导入与本地媒体存储：可从媒体服务器导入资源；社区版或媒体服务器不可达站点可改用本地媒体存储与路由。
  • 播放能力：自动配置雪碧图、自动播放开关与响应式尺寸嵌入代码、跨域播放嵌入、可配置 HLS TTL。
  • 上传与编目：上传表单页签化、编目字段精简、资料显示名同步 sys_user。
  • 权限界面：取消独立「保存访问策略」按钮，策略随「保存权限」一并提交；下载开关三态继承、拒绝原因分档、栏目 / 分类策略贯通媒体原件。
  • 客户端表单控制器：运行时与站点包贯通，站点包可声明表单控制器脚本。
  • 重复组编辑：修改显示名称后画布卡片即时同步。
  • 实时监控：按本地时区显示，并补充播放状态 / 观看时长 / 流量。
  • 国际化：批量补齐管理端 393 条五语译文（28 个文件），另补「版本与授权」页 146 条。
  • 社区版拆分：edition/community.json 仓库清单、overlay 覆盖层与 scripts/edition/ 生成 / 校验脚本。
  • 首站引导：站点列表为空时站点包页仍可导入。

✓ 修复

  • 音频无法播放：修复播放链路并重做 music-player 预览。
  • 资源下载：改为附件下载并给出准确拒绝原因，资源类型精简。
  • 上传失败资源复传被哈希去重短路（表单提交报「媒体资产不可引用」）。
  • 非 PAGE 内容打开编辑器不再误报「只有 PAGE 类型可以作为页面渲染」。
  • 播放会话超时收口改按最后一次心跳判活。
  • 字幕 VTT 路径修复，并透出 AI 能力状态。
  • 中文乱码：cms-core 三处中文注释 / 字符串的 UTF-8 被 GBK 误读问题。
  • 审计与日志保留删除真正执行并分批（原 LIMIT 方式实际不生效）。
  • 待办列表只显示 UUID：直出内容标题并按站点与对象权限过滤，避免点开即 403 / 404。
  • native-image 工作流未检出子模块：samples/react-dam 为独立仓库，打包需要完整源码树。

升级指引

  1. 备份数据库与 config/ 目录；
  2. 用 12.0.2 安装包替换可执行文件（原生版替换 bin/powercms(.exe)，管理端前端已内嵌，请使用本次分发包）；
  3. 首次启动由 Flyway 自动执行 V159 → V162 迁移（均为向前兼容的增量变更）；
  4. 启用版本分层时确认 powercms.license.enabled / enforce-edition-boundaries 配置，并在管理端「版本与授权」导入离线授权；
  5. Windows 需要服务化执行 install.ps1 -Service，Linux 执行 install.sh。

一句话：本版本主线是文档解析与知识库（RAG）从需求规格到可运行链路的完整落地，并捎带交付站点应用部署、统计报表当日可见、Windows 服务化安装与原生镜像稳定性修复。

更新记录

＋ 新增

  • 文档解析与知识库（RAG）：贯穿 docreader → dockb → search → ai，交付能力发现 / 任务提交 / 任务查询客户端契约、结构驱动分块器、分块索引与逐块向量、分块修订比对。
  • 知识库管理台：文档列表 / 详情 / 分块抽屉、批量操作、解析结果预览、引用链接自检、扫描件与 OCR 质量标记。
  • 站点应用部署（webapps）：React / Vue 前端部署到 webapps/{siteKey} 并自动匹配 API 路径。
  • React 数字资源库站点包样例：可导入的前端站点包（本次随发布交付）。
  • 统计报表当日可见：新增日内增量聚合任务，当天数据不再等次日凌晨。
  • Windows 服务化安装：install.ps1 -Service，经 WinSW 注册 Windows 服务（开机自启 + 崩溃自动拉起）。
  • 会员体系：会员注册审核、会员资源库条目、资源分享（新增 V156 / V157 / V158 迁移）。

◈ 优化

  • 离线安装：Windows 包内置 components/WinSW-x64.exe，支持完全离线的服务化安装（带镜像回退与体积校验）。
  • 数字资源库：媒体列表新增 folderPath 按目录浏览；内容引用 / 媒体引用在编辑器中按列表选择。
  • 媒体服务器：启动时凭 client_secret 登记端点（/api/v1/knox/register），已注册则保持原配置。
  • 向量缓存与配额：跨文档向量复用、TTL 与容量上限清理、缓存效果可观测；批量回填的 token 与并发上限支持站点级覆盖。
  • 内容管理：内容搜索页支持归档、删除已归档内容与批量操作；会员分组分配与会员解锁。
  • 检索质量：跨源加权 RRF 融合、本地轻量重排与模型重排接入检索链路（默认关闭）、父块上下文扩展。
  • CI：原生镜像工作流新增 targets 输入与动态矩阵；原生构建 locale 参数收敛为 -H:IncludeLocales=zh-CN。

✓ 修复

  • 知识库"永远搜不到"：分块文档缺失 _visibleGroups 导致全部被 ACL 拦截。
  • 凌晨 T+1 聚合一直失败：日聚合方法自调用绕过 Spring 代理，REQUIRES_NEW 事务从未生效。
  • 原生镜像首启崩溃：@Lazy 自注入改为 ObjectProvider，规避运行期 CGLIB 懒代理与 AOT 代理冲突。
  • 站点应用入口 404：无尾斜杠请求改为 302 补斜杠并保留查询参数。
  • Windows 干净系统无法启动：安装包随附 VC++ 运行库 vcruntime140*.dll。
  • 引用链接原先指向 POST 端点导致点击 405，已改指真实换票端点。
  • OpenSearch 端到端测试索引泄漏（真实集群曾累积 92 个残留索引）。
  • content ↔ workflow 循环依赖：以依赖倒置解耦，恢复 Modulith 架构约束。

升级指引

  1. 备份数据库与 config/ 目录；
  2. 用 12.0.1 安装包替换可执行文件（原生版替换 bin/powercms(.exe)，admin-ui/dist 已内嵌二进制）；
  3. Windows 需要服务化执行 install.ps1 -Service，Linux 执行 install.sh；
  4. 首次启动由 Flyway 自动执行 V138 → V158 迁移（均为向前兼容的增量变更，建议先建两侧备份）。

更新记录

＋ 新增

  • 身份与权限：组织 / 用户 / 角色、对象级 ACL（继承与打破继承）、OAuth 与 API Token、失败登录锁定。
  • 站点与环境：多站点多环境、域名校验、站点蓝图、组件健康检查矩阵。
  • 内容模型：内容类型、19 类字段控件、内容关系（含自引用）、分类法、类型复制与模型设计器画布拖拽。
  • 内容与版本：不可变版本快照、字段级差异、版本对比 / 恢复、定时发布与"时间机器"回放。
  • 媒体与 Knox：媒体库与版本、秒传去重、Knox 后处理回调、播放令牌与防盗链。
  • 工作流与发布：可版本化流程、四眼会签、定时发布 / 撤回；Release → Artifact → Deployment 三级模型、原子回滚与发布门禁。
  • 交付与检索：REST、按站点动态 Schema 的 GraphQL、MVC 渲染与渲染缓存；管理索引与访客索引隔离。
  • 统计与互动：访问采集与聚合、评论、问卷、考试、聊天室、广告、留言板。
  • AI 能力（默认关闭）：模型路由、站内问答、自动草稿、混合检索、知识图谱、智能体工作台、内置 MCP Server。
  • 样例与迁移工具：React 新闻站 / Vue 知识库两套站点包，V11 迁移工具包。

◈ 优化

  • 一套代码、多种数据库：H2 / PostgreSQL / MySQL（8.4 与 5.5 双版本）/ 金仓 KingbaseES / 达梦 DM8 按 profile 自动切换，迁移脚本方言 token 化，业务代码零改动。
  • 5 分钟开箱即用：默认 H2 文件库零外部依赖，一键安装脚本支持 Git / Nginx / OpenSearch 组件离线安装。
  • 原生打包：GraalVM native-image 一次产出 Windows x64 / Linux x64 / Linux arm64（arm64 为交叉编译），管理端前端整体内嵌。
  • 中文场景可用：自研 OpenSearch 中文分词插件（smartcn）、standard / ik / ICU 分析器，管理端 6 语言。
  • 内容访问统一判定链：条件受限内容不进静态产物，公开档过滤与缓存失效统一生效。
  • 管理端体验：模型设计器结构控件拖入画布、富文本富媒体对象编辑、系统日志双轨采集与观测。

✓ 修复

  • P0 扩展回归 15 项：CSRF 放行 /graphql/**、冻结站点写入返回 423、内容字段类型与必填校验、富文本 iframe 限站内 /media-play/、部署凭据脱敏、Token 过期 401 语义、预览拒绝写审计等。
  • 检索域：管理索引正文装配、向量重建脱离 PENDING 死锁、访客检索匿名 401、访客索引重建口径统一。
  • AI / 知识图谱域：模型配置词表归一、KG 边漂移对账、知识库访客索引泄露（P0）、时间列时区。
  • 媒体域：DEF-MS-01 ~ 05 与观察项闭环、i18n 运行期文案稳定化。
  • 平台域：/assets 嵌套静态资源被 SPA catch-all 遮蔽、静态资源删除后返回 404 而非 500。
  • 原生化首启竞态：内置角色种子双重检查与 saveAndFlush 冲突复查。
